# 视觉目标卡 · 药品主数据变更听写系统

> 本文件是**结构化视觉目标卡**（Phase 1 产出）。本轮运行环境**不具备图像生成能力**，因此**不生成、不伪造概念图**；`docs/screenshots/` 存放 Phase 4 采集的**真实运行截图**，两者分开标注、不得互相冒充。

> **2026-11-16 界面规范补建修订**：按 `uis/UI_BASELINE.md` 第四、五节与 WCAG 1.4.3 复核后收敛了三处目标值——①警告色由琥珀 `#C58B2A` 加深为深琥珀 `#9C6516`（原值作状态字与状态底只有 2.96:1）；②次要文字由 `#8A8A8A` 改为暖灰 `#6B665F`（原值对米白底 3.14:1，达不到正文 4.5:1）；③依据出处引用块去掉 3px 砖红左边线，改发丝边框——砖红在本产品里只表示「必须处理」（要素缺失、已驳回、出站失败），不当装饰边框。理由逐条记在 `docs/concepts/visual-target-gap.md`，取舍理由见 `docs/ui-stack.md`。

- **交付形态**：桌面常驻小工具（PySide6 托盘常驻 + 主窗口），**无 HTTP 服务面、无 Web 控制台**
- **画面类型**：桌面窗口 + 系统托盘图标（不画终端、不画大屏、不画浏览器）

## 1. 三个状态

### 起始态

主窗口已开，顶部一行灰字「本地识别已就绪 · 药品目录已同步 09:12」，中间一条长按钮「按住 说话」，下方是**空的条目表**（表头：药品码 / 字段 / 现值 / 应为值 / 依据 / 状态），左下角小字「今日 0 条待确认」；系统托盘有一个圆形药事岗图标。

### 首个可用瞬间

长按钮变砖红并显示「● 录音中 00:12」，按钮右侧实时冒出一行行识别文字（每 0.6–1 秒一句，**不逐字**）；文字左侧竖排两个小标签「药事岗」「临床科室」表示说话人。松手约 2 秒后，条目表**多出一行已填好的草稿**：

| 药品码 | 字段 | 现值 | 应为值 | 依据 | 状态 |
|---|---|---|---|---|---|
| `<示例药品码>` | 规格 | 0.25g | 0.5g | 00:08–00:15 药事岗 | 草稿 |

「依据」单元格带下划线，点击后弹出一小条引用原文（浅黄底 + 左侧竖线）。

### 成形态

窗口左栏变成**按状态分组的待办**（草稿 2 · 待确认 1 · 已提交 5），右栏是选中条目的详情：上半是药品目录读回的现值与建议改为值，下半是**依据出处三行**（发言人 / 起止时间 / 原话，每行前带说话人标签与时间戳），底部两个按钮「确认并提交」「退回修改」；状态为「已提交」的行右侧显示主数据系统回执号与回执时间（墨绿色）。

## 2. 视觉语言

| 项 | 取值 |
|---|---|
| 主色 | 石板蓝 `#2F5D8C`（主按钮、选中行、链接） |
| 强调色 | 砖红 `#C0503A`（录音中、退回、必填缺失标红） |
| 成功 | 墨绿 `#3F7A4F`（已提交、回执号） |
| 警告 | 深琥珀 `#9C6516`（待复核、目录已过期提示条；对白底 4.90:1） |
| 底色 / 卡片 | 米白 `#F6F4EF` / 白 `#FFFFFF`（行分隔 `#E4E0D8`） |
| 正文 / 次要文字 | `#2B2B2B` / 暖灰 `#6B665F`（对米白底 5.18:1） |
| 字体 | 中文：`-apple-system` / 「苹方」/「微软雅黑」；数字与代码列用等宽「SF Mono / Consolas」 |
| 信息层级 | 条目表（最显眼）→ 当前条目详情 → 依据原文（引用块最弱，浅黄底 `#FBF3D3` + 发丝边框） |

| 状态色映射 | 草稿=灰蓝 · 待复核=琥珀 · 已提交=石板蓝 · 已确认=墨绿 · 已驳回=砖红加粗 · 已退回=紫灰 · 要素缺失=砖红 |

## 3. 必须可达的约束

- 「实时出字」依赖增量推流主路径（`feed_chunk()` 增量推流），CPU 上按 **0.6–1 秒一句**承诺，**不画逐字级动画**；麦克风采集经 `soundfile` / `ffmpeg` 统一到 16 kHz 单声道。
- 热词包在启动时由入站读的药品目录生成，热词生效范围只覆盖药品名 / 剂型 / 规格 / 厂家，**不承诺**对院内自定义俗名全命中。
- **不画**情绪曲线、说话人置信度雷达、音频波形炫技等当前依赖做不出的元素；**不画** WebGL / 3D。
- 麦克风权限、模型首次下载、目录同步失败三个状态用**文字条**（灰 / 砖红）表达，不用弹窗特效。
- 说话人编号是**录音内匿名编号**，仅作辅助列；业务判据是**原话 + 绝对毫秒区间**。

## 4. 与实测截图的关系

`docs/screenshots/` 下的图片是**真实运行产物**（终端会话、界面离屏渲染、导出报告片段），由实际命令复现。本卡是**目标**，截图是**实测**，两者在信息密度、留白密度与视觉完成度上**必然存在差距**——差距由 `docs/concepts/visual-target-gap.md` 如实记录，不得声称完全一致。
