> 两者不会完全一致；此处逐条列出差异点，不声称已达成视觉目标。

### 2026-11-16 补建时收敛的三处目标值

| 项 | 原目标 | 收敛后 | 依据 |
|---|---|---|---|
| 警告色 | 琥珀 `#C58B2A` | 深琥珀 `#9C6516` | 原值作状态字（2.96:1）与作状态底压白字（2.96:1）都不达 WCAG 1.4.3 的 4.5:1；收敛后两种用法都是 4.90:1 |
| 次要文字 | `#8A8A8A` | 暖灰 `#6B665F` | 原值对米白底 3.14:1，达不到正文 4.5:1；收敛后 5.18:1（白底 5.69:1） |
| 引用块左边线 | 3px 砖红 | 发丝边框 | 砖红在本产品只表示「必须处理」（要素缺失、已驳回、出站失败）；拿来当装饰边框会让「危险」的语义变钝，也让每行依据都变成一次告警 |

配色 token 已按目标落地；以下为仍有差距的部分。

## 差距清单

1. **信息密度**：目标要求表格行高 32px，实测主表行高锁定为 36px（`ROW_HEIGHT["standard"]`，`uis/UI_BASELINE.md` §三 的标准档），与目标差 4px；实测更利于双行文字的现值/应为值不挤。
2. **字体层级**：目标用 px 定义字号阶梯，PySide6 QSS 用 px（Qt 无 rem），实测字号层级齐全但字形渲染与苹方/雅黑目标有平台差异。
3. **引用块**：目标依据出处三行用浅黄底 + 发丝边框，实测详情页引用行已套用该样式，离屏渲染字体较小，可读性弱于目标稿描述；未选中条目时引用行呈禁用态（米白底 + 占位色），目标未定义该态。
4. **说话人标签**：目标竖排两个小标签，实测用行内文字标签（spk0/spk1）替代，未做竖排视觉。
5. **动效**：实测已接 `QPropertyAnimation`（toast 淡入，时长取 `theme.duration_ms("dur-2")`），并提供 `theme.set_reduced_motion(True)` 降级开关（等价 `prefers-reduced-motion: reduce`，降级后时长归零）；目标未约束动效，属于超出目标的增益。
6. **托盘图标**：目标为圆形药事岗图标，实测用程序化绘制的圆形十字图标，语义一致但细节简化。
7. **响应式**：目标未定义响应式，实测实现「1200 宽以上左右分栏 / 1200 以下上下排布」两档——目标原写 1280/768，实测把断点上移到 1200，原因是条目表 8 列、药品码 23 位，横向排布在 1200 以下必然出横向滚动条并把「回执时间/经办人」挤出视野。此为超出目标的重新取舍。
8. **焦点可见**：目标未约束，实测按 `uis/UI_BASELINE.md` §五给所有可聚焦控件补了 2px 焦点环（Qt 的 QSS 不认 CSS `outline`，改用 `:focus` 改 border 实现）；截图不含焦点态，属截图维度未覆盖。
9. **等宽数字**：目标未约束，实测对药品码/回执号/回执时间与含数字的现值/应为值施加 OpenType `tnum`（等价 `tabular-nums`），保证纵向数字不跳字。

## 结论

配色与信息层级按目标落地（含 2026-11-16 补建时按对比度收敛的三处目标值，理由已留痕），字符级像素对齐、竖排标签、焦点态截图仍未覆盖。截图为真实离屏渲染产物，非设计稿；两者差距如上，不声称完全一致。
